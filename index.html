FAQ

Les questions essentielles.

Est-ce que AutonomIA travaille sans moi ?

Oui, pour les workflows que vous avez configurés. Les actions sensibles peuvent demander une validation humaine.

Mes données sont-elles utilisées pour entraîner une IA ?

Le traitement réel dépendra des fournisseurs techniques retenus. La version commerciale devra préciser les sous-traitants, finalités, durées et transferts dans sa documentation RGPD.

Puis-je résilier ?

Oui selon les conditions contractuelles applicables à l'offre choisie. Les modalités exactes doivent figurer dans les CGV.
